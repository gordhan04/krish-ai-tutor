# Development Roadmap: Phase A to J

## Phase A: Foundation (Active)
- Repository structure, FastAPI backend, Next.js frontend, database models, initial migration, seed curriculum, security foundations.

## Phase B: Curriculum & Ingestion
- PDF document parser, structural chapter/topic detector, concept extractor, admin inspector UI.

## Phase C: Curriculum-Aware RAG
- Content chunking with hierarchical metadata, embedding generation, vector similarity retrieval with strict filtering.

## Phase D: AI Tutor Engine
- Explicit state machine, Socratic prompts, 5-level progressive hint ladder, structured output contracts.

## Phase E: Adaptive Assessment
- Grounded question generation, dynamic difficulty adjustment (Levels 1-5), rubric evaluation, misconception catalog.

## Phase F: Student Model & Analytics
- Append-only learning event stream, deterministic mastery scoring, spaced repetition schedule, learning gain metrics.

## Phase G: Voice Tutoring
- Web Speech API integration, backend speech fallback, voice modes (Teach, Socratic, Quiz, Explain-it-Back).

## Phase H: Healthy Gamification
- Outcome-tied XP, Leveling curve, Daily Missions, Streaks with rest days, Chapter Boss Battle.

## Phase I: Parent Dashboard
- Progress heatmaps, weak area alerts, learning gain comparison, actionable guidance for parents.

## Phase J: Hardening & Production
- Comprehensive test coverage, security audit, token cost optimization, Docker containerization.
